# Rat Race for the TI-994/A

This was a game, similar to the game TGIF, that I wrote in TI Extended Basic.  To play it, you will need to have a 32k memory expansion and the TI Extended Basic cartridge. I recently ran this on the ti99sim-sdl emulator for Linux and it ran a bit slow.  I remember running it on a real machine in the past and recall it running faster, so you may want to do that.
This is the procedure that I used to run the game.

1. Run the emulator with the following command (replace the ctg portion with the name of your extended basic cartridge):<br><br>
`ti99sim-sdl --NTSC --dsk1=RatRace-Latest.TIDisk tiextbas.ctg`

2. On the TI screen, select option 2 to run TI EXTENDED BASIC.

3. Once in BASIC, run the following commands:<br><br>
   OLD "DSK1.RATRACE"<br>
   RUN<br>

That should run the game.  Because the game takes up most of the RAM, it may take a minute between the BASIC commands and during play.  

# GAMEPLAY

The game is similar to TGIF on the Atari 800 system.  The game can be played with 1 or 2 people.  The computer (TI) will automatically play if you only choose 1 player. Choose a money goal (10,000 - 90,000) and then the game should start.

In the game, you want to try to accumulate money to get to the goal.  This is done by selecting days.  Some are good, some are bad.  There are opportunities to buy and sell investments, to gamble with lottery tickets and the color wheel and to gain or lose money through events.  Make it through the Rat Race to the goal first and live the life of luxury!
